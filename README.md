# الدال والمدلول معًا — المستودع الرابع (طبقة الدلالة)

مستودع الدال والمدلول في منظومة المشروع (مع الغانم وحامل وتاقول-Algebra): طبقة المعنى التي تجلس في العمود الفقري **بعد الإملاء وقبل المبنيات** — فالصوت يُصاغ رسمًا، والرسم يُلدغ دلالة، والدلالة تحمل البنية.

## المنهج
كتب الشخصية الثلاثة لتقي الدين النبهاني (المقتبسات النصية في `data/nabhani_sources.json` بدرجة E): المفاهيم معاني الأفكار لا معاني الألفاظ؛ واللفظ دالّ والمعنى مدلول؛ والوضع تخصيص لفظ بمعنى؛ واللغة وضع لا توقيف، وطريقها الرواية لا العقل؛ والدلالات ثلاث مغلقة؛ والنسب إسنادية وتقييدية وإضافية؛ والحقيقة استعمال اللفظ فيما وُضع له والمجاز بقرينة؛ والمنطوق ثلاثة والمفهوم خمسة — لا ثالث فيهما.

## محرك SLGE العاشر (`src/slge/slge_dalil.py`)
DL1 الوضع (تخصيص لفظ بمعنى، بعينة معلنة واستيفاء بالرواية) · DL2 الدلالات الثلاث مغلقة · DL3 الحقيقة والمجاز (المجاز بلا قرينة مرفوض) · DL4 النسب الثلاث · DL5 المنطوق/المفهوم مغلقان · DL6 مفهوم/معلومات (المفهوم له واقع مدرَك).

## الاختبارات المباركة
`python3 tools/verify_repo.py` — بصمات + المحركات العشرة + فحوص الدال والمدلول.
